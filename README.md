## Project Description
Woodex is an eCommerce HTML template designed for a furniture store. It offers a clean, modern design with sections for featured products, blog posts, and customer engagement through newsletters. The template is built with HTML, CSS, and JavaScript, and includes a style guide for consistent design.

## Project Overview
The project includes:
- A responsive header with search and user action buttons.
- A sidebar for language and currency selection.
- Sections for hero banners, about the store, popular products, blog posts, and newsletter subscription.
- A footer with contact information and social media links.

## Style Guide
The project uses a dedicated style guide located in `style-guide.md` which defines:
- Google Fonts and Ionicons imports.
- Color palette variables.
- Typography settings.
- Spacing, shadow, and transition styles.
